# Anima

Native Anima text-to-image and ElectronGirl reference adapter integration. Install through the managed SwarmUI updater; it installs SECoursesAudioTools, whose Anima gallery guider contains the reference adapter (adapted from ElectronGirl's ComfyUI-Anima-Ref-Adapter), so no separate node pack is needed.

Download the Anima Core Bundle. It contains base v1.0 INT8 ConvRot, Qwen3 600M, the reference adapter and the existing shared Qwen-Image VAE. BF16 is available separately. Anima arithmetic uses BF16 even when storage is INT8.

Apply the text-to-image or reference preset. For transfer, enable Anima Reference and upload one still image in Anima Reference Image, or attach it to the prompt. The explicit reference control takes priority; otherwise the first prompt attachment is used. Write scene, pose and framing; identity and some style come from the image. Euler/simple, 30 steps, CFG 4.5, shift 3, adapter strength 1, reference guidance 4.5 and APG are the starting settings.

The normal prompt, negative, LoRA, resolution and seed controls remain available. Prompt batches accept added prompts, .txt files or a folder. Seeded `{a|b}` choices are passed through Swarm's native random prompt processor. Reference mode preserves the original main latent, so native image-to-image/masks and subsequent refiners remain in Swarm's workflow. The adapter targets the base sampler only; a separate refiner uses its native sampler. Fine accessories and strong painterly styles can drift.

Both presets sample at about 1 MP (1024x1024), then use the native PostApply pixel-Lanczos 2x refiner for a 2048x2048 final image. Refiner Steps 40 with Control 0.3 gives a 12-step detail pass. The reference adapter is off for that pass. Anima is made for 512x512 to 1536x1536: direct 2048x2048 text to image drew malformed arms and a malformed falcon in our A/B where the two-pass recipe stayed clean, and direct 2048x2048 reference sampling produced checkerboard artifacts with the author's native graph in BF16 as well as INT8; latent-space 2x refinement also softened line work. Decode, pixel-scale, re-encode and denoise 0.3 preserved clean lines. Disable the Refine / Upscale group to keep the 1 MP result.

The presets start every prompt with `masterpiece, best quality, score_7, newest, highres, absurdres, safe,` and use the negative `nsfw, worst quality, low quality, score_1, score_2, score_3, artist name, signature, watermark, blurry, jpeg artifacts, chromatic aberration, bad anatomy, bad hands, extra fingers` (the model card's recommendations plus the adapter's showcase tags). Anima_Enchance_Prompt_Feed_For_LLMs.txt in the downloader explains the tag order.
